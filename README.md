# 🚀 Simple HTTP Web Server (Node.js + TypeScript)

Минималистичный, быстрый и отказоустойчивый веб-сервер, написанный на **TypeScript** с использованием встроенного модуля `node:http` без сторонних веб-фреймворков. 

Проект разработан с учетом лучших практик (Senior-style): логика декомпозирована на чистые изолированные функции, внедрена защита от инфраструктурных сбоев, конфигурация управляется через переменные окружения, а раздача статики оптимизирована с помощью потоков (Streams). Сервер полностью готов к масштабированию в режиме кластера через PM2.

---

## 🏗️ Архитектура и жизненный цикл запроса

Архитектура построена на плоском конвейере обработки (Flat Pipeline). Каждая стадия запроса изолирована, что предотвращает падение сервера при некорректных действиях пользователя.

```text
[Клиент] 
   │
   ▼
[Порт :PORT] ──► (Инициализация: проверка EADDRINUSE)
   │
   ▼
[http.createServer] 
   │
   ├──► [parseSafePath] ──────► (Декодирование URL, защита от дефектов)
   │
   ├──► [startsWith] ─────────► (Валидация безопасности Directory Traversal)
   │
   ├──► [resolveStaticFile] ──► (Умный поиск файлов: прямой -> .html -> index.html)
   │
   ▼
[fs.createReadStream] ──► [stream.pipe(res)] ──► [Ответ клиенту]
