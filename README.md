# 🚀 Simple HTTP Web Server (Node.js + TypeScript)

Минималистичный, быстрый и отказоустойчивый веб-сервер, написанный на **TypeScript** с использованием встроенного модуля `node:http`. Проект разработан с учетом лучших практик (Senior-style): включает обработку системных ошибок, конфигурацию через переменные окружения, раздачу статики с использованием потоков (Streams) и готов к масштабированию в режиме кластера через PM2.

---

## 🏗️ Архитектура и жизненный цикл запроса

Сервер спроектирован так, чтобы не блокировать Event Loop при работе с диском и корректно обрабатывать инфраструктурные сбои.

```text
[Клиент] ---> (Порт :3000) ---> [server.on("error") Проверка занятости порта]
                                     |
                                     v
                        [http.createServer]
                                     |
                                     v
                 [Потоки: fs.createReadStream] ---> [Ответ клиенту]
