# 🚀 Simple HTTP Web Server (Node.js + TypeScript)

Минималистичный, быстрый и отказоустойчивый веб-сервер, написанный на **TypeScript** с использованием встроенного модуля `node:http` без сторонних веб-фреймворков. 

Проект разработан с учетом лучших практик (Senior-style): логика декомпозирована на чистые изолированные функции, внедрена защита от инфраструктурных сбоев, конфигурация управляется через переменные окружения, а раздача статики оптимизирована с помощью потоков (Streams). Сервер полностью готов к масштабированию в режиме кластера через PM2.

---

## 🏗️ Архитектура и жизненный цикл запроса

Архитектура построена на плоском конвейере обработки (Flat Pipeline). Каждая стадия запроса изолирована, что предотвращает падение сервера при некорректных действиях пользователя.

```text
[Клиент] 
   │
   ▼
[Порт :PORT] ──► (Инициализация: проверка EADDRINUSE)
   │
   ▼
[http.createServer] 
   │
   ├──► [parseSafePath] ──────► (Декодирование URL, защита от дефектов)
   │
   ├──► [startsWith] ─────────► (Валидация безопасности Directory Traversal)
   │
   ├──► [resolveStaticFile] ──► (Умный поиск файлов: прямой -> .html -> index.html)
   │
   ▼
[fs.createReadStream] ──► [stream.pipe(res)] ──► [Ответ клиенту]

## 📖 Техническая документация и исходный код

Проект декомпозирован на изолированные логические блоки. Вы можете перейти к детальному описанию архитектуры или сразу к файлам кода по ссылкам ниже:

### Документация
* [📂 Спецификация статического роутера (resolveUrl.ts)](./docs/RESOLVEURL.md) — подробный разбор конвейера валидации входящих URL, паттерна «Массив кандидатов» и защиты от утечки данных.
* [🏷️ Спецификация карты типов (MIME_TYPES)](./docs/MIMETYPES.md) — описание поддерживаемых контент-типов, защита от MIME Sniffing и инструкция по безопасной обработке неизвестных расширений.

### Исходный код (`src/`)
* [📄 Точка входа сервера (index.ts)](./src/index.ts) — инициализация `http.createServer`, прослушивание портов и глобальный перехват инфраструктурных ошибок.
* [📄 Модуль роутинга (resolveUrl.ts)](./src/resolveUrl.ts) — чистая функция обработки входящих запросов, валидации и генерации стримов.
* [📄 Конфигурация типов (type.ts)](./src/type.ts) — экспортируемый словарь `MIME_TYPES`.

## 📂 Структура проекта

Финальная архитектура файлов и каталогов выглядит следующим образом:

```text
.
├── dist/                    # 📁 Скомпилированный production-код (генерируется tsc)
├── docs/                    # 📁 Архитектурная документация проекта
│   ├── MIMETYPES.md         # Спецификация карты медиа-типов контента
│   └── RESOLVEURL.md        # Спецификация логики статического роутера
├── src/
│   ├── static/              # 📁 Папка со статическими файлами (HTML, CSS, JS, медиа)
│   │   ├── main/
│   │   │   └── index.html   # Главная страница (дефолтный роут сервера)
│   │   └── about.html       # Пример страницы для Pretty URL (/about)
│   ├── index.ts             # 📄 Точка входа приложения (инициализация http.createServer)
│   ├── resolveUrl.ts        # 📄 Логика обработки и стриминга запросов
│   └── type.ts              # 📄 Экспортируемый объект конфигурации MIME_TYPES
├── .env                     # Локальные переменные окружения (игнорируются Git)
├── .env.example             # Шаблон конфигурации для команды
├── .gitignore               # Исключения для Git-репозитория
├── package.json             # Зависимости и npm-скрипты автоматизации
└── tsconfig.json            # Конфигурация компилятора TypeScript
