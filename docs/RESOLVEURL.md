# 📂 Модуль статического роутинга (`resolveUrl.ts`)

Этот модуль инкапсулирует в себе всю низкоуровневую логику раздачи статических ресурсов, валидации входящих URL, защиты сервера от Path Traversal атак и оптимизированного стриминга файлов. 

Благодаря декомпозиции, основной файл сервера остается чистым и выполняет роль классического оркестратора.

---

## ⚙️ Алгоритм работы (Жизненный цикл обработки)

Каждый запрос, переданный в функцию `resolveUrl`, проходит строгий конвейер проверок перед тем, как файл начнет считываться с диска:

```text
[HTTP Request]
      │
      ▼
┌───────────────┐      Нет      ┌─────────────────────┐
│ parseSafePath │ ────────────► │ 400: Bad Request    │
└───────┬───────┘               └─────────────────────┘
        │ Да
        ▼
┌─────────────────────────┐      Нет      ┌─────────────────────┐
│ Проверка startsWith()   │ ────────────► │ 403: Доступ запрещен│
└───────┬─────────────────┘               └─────────────────────┘
        │ Да (Внутри PUBLIC_DIR)
        ▼
┌────────────────────┐
│ resolveStaticFile  │ ──► Перебор кандидатов: 1. Прямой -> 2. .html -> 3. index.html
└───────┬────────────┘
        │
        ├──► [Файл найден] ─────► [fs.createReadStream] ──► 200 OK (Стрим файла)
        │
        └──► [Файл НЕ найден] ──► 404: Файл не найден
