# 🏷️ Спецификация карты типов (`MIME_TYPES`)

Этот модуль содержит словарь (карту) поддерживаемых сервером медиа-типов (MIME-типов). Он необходим для того, чтобы сообщать браузеру пользователя, какой именно тип контента ему передается в HTTP-ответе.

---

## 🧐 Зачем это нужно?

Когда сервер отправляет файл через стрим, он обязан добавить HTTP-заголовок `Content-Type`. Без этого заголовка браузер не сможет правильно обработать полученные данные:

* **Без MIME-типа для CSS:** Браузер загрузит файл стилей, но заблокирует его применение к HTML-странице из-за строгой политики безопасности (**MIME Sniffing**).
* **Без MIME-типа для JS:** Браузер не сможет выполнить скрипты, посчитав их обычной текстовой строкой.

---

## 📋 Список поддерживаемых типов

На данный момент сервер из коробки поддерживает следующие типы данных:

| Расширение | MIME-тип | Описание контента |
| :--- | :--- | :--- |
| `.html` | `text/html; charset=utf-8` | Веб-страницы (с принудительной кодировкой UTF-8) |
| `.css` | `text/css` | Каскадные таблицы стилей |
| `.js` | `text/javascript` | Скрипты JavaScript |
| `.png` | `image/png` | Изображения формата PNG |
| `.jpg` | `image/jpeg` | Изображения формата JPEG / JPG |
| `.gif` | `image/gif` | Анимированные и статические изображения GIF |
| `.json` | `application/json` | Конфигурации и структурированные данные API |

---

## 🛡️ Безопасность (Fallback-тип)

Если пользователь запрашивает файл, расширения которого нет в этой таблице, сервер автоматически подставляет универсальный тип безопасности:

```typescript
const contentType = MIME_TYPES[ext] || 'application/octet-stream'
```
